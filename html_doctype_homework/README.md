# Завдання з HTML

У цьому наборі є:
- `index.html` — проста HTML-сторінка, у першому рядку якої вказано `<!DOCTYPE html>`.
- `doctypes.txt` — коротка інформація про версію HTML та DOCTYPE.

## Як перевірити
1. Відкрийте `index.html` у браузері.
2. Переконайтеся, що сторінка показує заголовок «Привіт, світе!».
3. Перевірте, що `<!DOCTYPE html>` стоїть у першому рядку файлу.
