# Учебная работа: DOCTYPE и версии HTML

## Состав архива
- `index.html` — учебная веб-страница с объяснением DOCTYPE, таблицей версий HTML и выводом.
- `doctypes.txt` — отдельный текстовый файл с примерами объявлений DOCTYPE для HTML5, HTML 4.01 и XHTML 1.0.

## Как проверить
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Откройте `doctypes.txt` в любом текстовом редакторе.
4. Убедитесь, что первой строкой `index.html` является `<!DOCTYPE html>`.

## Как добавить работу в GitHub
1. Создайте новый репозиторий на GitHub (например, `html-doctype-dz`).
2. Загрузите в него файлы `index.html`, `doctypes.txt` и `README.md`.
3. Либо выполните в терминале из этой папки:

```bash
git init
git add index.html doctypes.txt README.md
git commit -m "Add HTML DOCTYPE homework"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/html-doctype-dz.git
git push -u origin main
```

Замените `ВАШ-ЛОГИН` и адрес репозитория на свои данные. Для отправки изменений нужен доступ к вашему GitHub-репозиторию.
