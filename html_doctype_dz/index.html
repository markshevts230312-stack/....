DOCTYPE и версии HTML

Учебная работа: зачем нужен DOCTYPE, как менялись версии HTML и почему современные страницы обычно используют HTML5.

1. Что такое DOCTYPE?

DOCTYPE — это объявление типа документа. Оно размещается в самом начале HTML-файла, перед тегом <html>. Браузер использует это объявление, чтобы выбрать стандартный режим отображения страницы.

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
</body>
</html>

Важно: в HTML5 используется короткое объявление <!DOCTYPE html>. Оно не указывает номер версии цифрами, но сообщает браузеру, что документ должен отображаться в стандартном режиме.

2. Основные версии HTML

ВерсияКраткое описаниеОбъявление DOCTYPE
HTML 2.0 Одна из первых стандартизированных версий языка, опубликованная в 1995 году. Использовались формальные объявления типа документа, связанные с DTD.
HTML 3.2 Стандарт 1997 года, включавший многие распространённые на тот момент возможности разметки. Например, публичный идентификатор W3C для HTML 3.2.
HTML 4.01 Стандарт 1999 года. Существовали варианты Strict, Transitional и Frameset. Зависел от выбранного варианта HTML 4.01.
XHTML 1.0 HTML, основанный на синтаксических правилах XML; требовал более строгого оформления разметки. Использовались объявления с идентификаторами XHTML 1.0.
HTML5 Современный подход к HTML, поддерживаемый актуальными браузерами. <!DOCTYPE html>

3. Почему объявление пишут первым?

  • Оно помогает браузеру выбрать стандартный режим отображения.
  • Оно должно находиться до любых HTML-элементов страницы.
  • В современном HTML объявление короткое и не требует ссылки на DTD.
  • Если объявление отсутствует или написано некорректно, браузер может включить режим совместимости со старыми страницами.

4. Что хранится в doctypes.txt?

В файле doctypes.txt собраны примеры объявлений для разных типов документов и краткие пояснения к ним. Это отдельный текстовый файл, как требует задание.

Для новой учебной или рабочей страницы обычно достаточно первой строки:

<!DOCTYPE html>

5. Вывод

DOCTYPE — важная часть структуры HTML-документа. Он должен стоять в первой строке файла и помогает браузеру правильно интерпретировать разметку. В старых версиях HTML объявления были длинными и ссылались на DTD. В HTML5 применяется простая запись <!DOCTYPE html>, которую рекомендуется использовать в новых проектах.
